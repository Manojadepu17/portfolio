## 🔧 Customization

### Change Colors
Edit CSS variables in `style.css` (lines 10-20):
```css
--primary-gradient: linear-gradient(90deg, #6366F1, #0EA5E9, #22D3EE);
--glow-color: #0EA5E9;
```

### Modify Hero Name
Edit in `index.html` (line ~75):
```html
<h1 class="hero-name">ADEPU<br>MANOJ</h1>
```

### Update Typing Text
Edit in `script.js` function `initTypingAnimation()` (line ~24):
```javascript
const textArray = [
    'Full Stack Developer',
    'AI Enthusiast',
    // Add more here
];
```

### Add Social Links
Update social icons in HTML (line ~95):
```html
<a href="YOUR_URL" class="social-icon">
    <!-- SVG icon here -->
</a>
```

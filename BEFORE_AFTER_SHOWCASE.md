#### Education Card Hover Sequence:
```

        ┌─────────────────────┐

        └─────────────────────┘

        ─ → ─ → ─ → → → ─ →

Duration: 0.3-0.6s smooth transition

```

│ Solid background    │

│ Simple border       │
│ Flat appearance     │
└─────────────────────┘

        ╭─────────────────────╮
        ┃ Blurred background  ┃  ← Semi-transparent
        ┃ through card        ┃  ← Blur effect
        ┃ Soft, premium feel  ┃  ← Depth
        ┃ Modern appearance   ┃  ← Contemporary
        ╰─────────────────────╯
         ↓ ↓ ↓
